# bh-lampadas-sistema
Protótipo desenvolvido para o Projeto Integrador de Tecnologia da Informação da UFMS.
Sobre
O projeto busca desenvolver um sistema para facilitar a gestão de produtos e clientes da BH Lâmpadas, reduzindo o retrabalho e preparando a empresa para uma futura substituição do sistema Space Informática.
Funcionalidades disponíveis

Cadastro, edição e pesquisa de produtos e clientes.

Exportação de informações em CSV.

Identificação de produtos sem preço.

Registro de ocorrências relacionadas à privacidade.

Leitura experimental de arquivos TXT do Space.

Armazenamento local das informações.

Tecnologias utilizadas

Python, HTML, CSS e banco de dados SQLite.

Como executar

Instalar o Python 3.8 ou superior.

Baixar e extrair os arquivos do repositório.

Executar o arquivo INICIAR_WINDOWS.bat.

Abrir http://127.0.0.1:8765 no navegador.

Criar a senha de administrador no primeiro acesso.

O protótipo funciona localmente e não necessita de conexão com a internet para executar suas funcionalidades.

Testes

Os testes automatizados podem ser executados com o comando:

python testes_automaticos.py

Próximas etapas

A proposta é melhorar a interface, ampliar as funcionalidades de pedidos, avaliar a impressão na impressora matricial da loja e desenvolver uma versão final que possa ser instalada no computador.

Observação: este é um protótipo acadêmico. Ele não substitui o Space nem o Bling e não deve ser utilizado com dados reais sem validações adicionais.
